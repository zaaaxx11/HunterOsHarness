## 2. Arsitektur (6 layer, engine pluggable)
```
L5 Business  : (roadmap docs saja hari ini)
L4 Workflow  : pipeline scan S0–S7 versi slim (deterministik hari ini, multi-agent nanti)
L3 Skills    : port corpus HunterOS (_data/idea skills, roles, IDEA.md) sebagai konten; index + skill_view
L2 Tools     : registry eksplisit + scope-gate fail-closed + http_client + shell sandbox + probe modules
L1 Runtime   : run loop per-phase + EngineDriver protocol + event bus + budget/telemetry
L0 Kernel    : SQLite event-sourced ledger HASH-CHAINED (sha256 + Merkle per run), claim gate,
               evidence ladder, findings schema, project lock, secret redaction
```
- **EngineDriver protocol** (titik plug ala HUNT-ADAPTER/1 + cara hermes/Strix pasang brain): `plan(target) -> plan`, `execute_step() -> events`, `finalize() -> verdicts`. Hari ini: **DeterministicEngine** (recon → fuzz battery → probe modules → evidence → findings). Stub **LLMEngine** (LiteLLM, extra `[llm]`) siap sebagai skeleton + MockEngine untuk test — persis pola conductor MockAdapter HunterOS.
- **Probe modules (deterministik, port & perluas `core/fuzz.py`)**: security-headers, cookie flags, reflected-XSS canary, SQL-error signature, path traversal, open redirect, directory listing, debug/exposed files (/.env, /.git, /admin), method tamper, unauth-access diff, IDOR heuristic (increment id), form injection battery. Semua probe: baseline dulu, payload terkontrol, RATE-LIMITED, hanya same-origin/scope.
- **Claim gate native**: fungsi library + hook — finding tanpa artifact evidence (sha256) GAGAL dibuat (dipaksa di layer DB, bukan prompt); laporan hanya dari ledger. Semantik ladder: `candidate → verified` (verified butuh replay probe kedua sukses).
- Deps inti: `typer, rich, textual, httpx` (semua di-pin). Extras: `[llm] litellm`, `[dev] pytest, ruff, mypy`. Zero-dependency philosophy longgar: core jalan dengan 4 dep.

## 3. PracticeVault (demo "nemu vuln hari ini")
`examples/practice_target/` — app vulnerable kecil (stdlib `http.server`, tanpa dep tambahan, auto-start/stop by harness) dengan **8 vuln ditanam + answer_key.json**: (1) unauth /transfer, (2) forgeable cookie role=admin, (3) password dump md5 di /backup/users.sql, (4) reflected XSS di /search?q=, (5) SQL-error via ' di /login, (6) path traversal /download?file=, (7) open redirect /goto?url=, (8) missing security headers + directory listing /static. `hunter demo` = ARM→RUN→COLLECT→COMPARE vs answer_key (recall ≥ 7/8 = first-blood hijau) — ini sekaligus **bench P1** versi pertama.

## 6. Quality Gates ("no bugs", re-check selalu)
- pytest dual-OS (Windows lokal + CI ubuntu/windows), ruff + mypy clean, secret-hygiene scan.
- Enforcement tests: claim gate veto (finding tanpa evidence = BLOCKED), hash-chain tamper detection (mutasi payload = verified fail), scope gate (host luar scope ditolak fail-closed), redaction (token shape tak pernah masuk ledger mentah).
- Adversarial: probe tidak boleh mengubah state target (RoE default-deny), rate-limit semua probe, injection canary (data target berisi instrusi palsu → harness TIDAK mengeksekusi).
- Determinisme: demo run 3× hasil konsisten (ledger hash beda karena ts, tapi set findings + recall identik).
- Definition of "done" per modul: test hijau + QA review lulus + orchestrator approve.
